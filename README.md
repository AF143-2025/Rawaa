# منصة رواء | RAWAA Academy
> «تعلّم اليوم، واحمِ المستقبل.»

منصة تعليمية عربية متكاملة واحترافية متخصصة في تدريب وتأهيل مهندسي الشبكات، مدراء أنظمة Linux، وممارسي الأمن السيبراني والدفاع الرقمي، تجمع بين الشرح النظري العميق والتدريب العملي المعزول داخل المتصفح.

---

## 🌟 مميزات المنصة الرئيسية

1. **الهوية البصرية والواجهات:**
   - تصميم تقني فخم باللون الكحلي والأسود وتدرجات الأزرق السماوي والأخضر التقني والأرجواني السيبراني.
   - دعم كامل ودقيق للغة العربية والاتجاه من اليمين لليسار (RTL) مع خط **Cairo** المتميز ومصطلحات تقنية بخط **JetBrains Mono**.
   - تجاوب مثالي وسلس مع شاشات الحاسوب، الأجهزة اللوحية، والهواتف المحمولة.

2. **المسارات التعليمية التخصصية:**
   - **مسار هندسة الشبكات والاتصالات (Networking):** نموذج OSI، TCP/IP، IPv4/IPv6، Subnetting & CIDR، DNS، DHCP، ARP، Ports، Routing & Switching، والجدران النارية.
   - **مسار إدارة أنظمة وسيرفرات Linux:** أوامر سطر الأوامر، شجرة الملفات، الصلاحيات (chmod/chown)، إدارة العمليات والخدمات (Systemd)، وفحص السجلات.
   - **مسار الأمن السيبراني والدفاع الرقمي (Cybersecurity):** مثلث CIA، التشفير والتجزئة، ثغرات OWASP Top 10، تحليل السجلات الأمنية، والاستجابة للحوادث الرقمية (Incident Response).
   - **مسار المختبرات التفاعلية وتحديات CTF:** بيئات تدريب معزولة وتحديات صيد أعلام فورية التحقق.

3. **المختبرات التفاعلية المدمجة:**
   - **طرفية Linux المعزولة (Virtual Terminal):** محاكاة تفاعلية آمنة تدعم أوامر `pwd` و `ls -la` و `cd` و `mkdir` و `touch` و `cat` و `whoami` مع مهام تدريبية تدريجية ونظام تحقق فوري ونقاط إنجاز.
   - **محاكي وحاسبة Subnetting & CIDR:** حساب عناوين الشبكة والبث ونطاق الأجهزة والتمثيل الثنائي بدقة رياضية، مع تمارين تفاعلية ومقارنة TCP مقابل UDP ومحاكي فحص المنافذ (Port Scanner).
   - **مختبر التحقيق الجنائي والأمن السيبراني:** فحص سجلات المصادقة الحقيقية `/var/log/auth.log` لكشف هجمات القوة الغاشمة (Brute-force)، ومحاكي ثغرات حقن قواعد البيانات SQL Injection، ولوحة تحديات صيد الأعلام (CTF) مع أعلام بصيغة `RAWAA{...}`.

4. **نظام الدورات والدروس والتقييم:**
   - نظام إدارة تعليمي منظم يعرض المتطلبات، الأهداف، الفهرس، المشغل المرئي، والمحتوى التقني المنسق.
   - محرك اختبارات إلكتروني مع مؤقت زمني، وتصحيح آلي، وتفسير إجابات فوري، واحتساب نسبة النجاح.
   - حفظ تقدم الطالب والدروس المكتملة في قاعدة البيانات ومحلياً لضمان استمرارية التعلم من آخر نقطة.

5. **نظام الشهادات الرقمية المعتمدة:**
   - تصميم شهادة فاخر بإطارات ذهبية وعلامة مائية رقمية رسمية.
   - إصدار تلقائي برمز تحقق فريد (مثل `RAWAA-NET-XXXXX`) فور اجتياز اختبار الدورة بنسبة 70% فأكثر.
   - بوابة عامة ومفتوحة للتحقق من صحة وموثوقية الشهادات (`/verify` و `/verify/[code]`).

6. **لوحات التحكم والصلاحيات (RBAC):**
   - **لوحة تحكم الطالب (Student Dashboard):** تتبع الدورات المسجلة، متابعة آخر درس، مراجعة الإنجازات، واستعراض الشهادات المكتسبة.
   - **لوحة تحكم الإدارة (Admin Panel):** محمية بالصلاحيات ولا تسمح بالدخول غير المصرح، تتيح مراقبة المؤشرات الحقيقية، إضافة دورات جديدة، مراجعة الطلاب والشهادات، ونشر التنبيهات والإعلانات العامة.
   - ميزة التبديل السريع بين الحسابات التجريبية (Demo Accounts) لتسهيل الفحص والتقييم الفوري.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript (Strict Type Safety)
- **Styling:** Tailwind CSS + Custom RTL & Glassmorphic Utilities
- **Icons:** Lucide React
- **Celebration & UX:** Canvas Confetti
- **Database & Auth:** PostgreSQL / Supabase مع دعم طبقة تخزين محلية هجينة تعمل مباشرة دون انقطاع.
- **Typography:** Cairo (العناوين والنصوص) + JetBrains Mono (الأكواد والطرفية).

## 🚀 دليل التثبيت والتشغيل المحلي

### 1. المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث، تم التحقق والتطوير على Node v24).
- npm أو pnpm أو yarn.

### 2. تثبيت الحزم
```bash
git clone <repository-url>
cd radiant-curie
npm install
```

### 3. إعداد متغيرات البيئة (اختياري للربط مع Supabase)
انسخ ملف الإعدادات:
```bash
cp .env.example .env.local
```
ضع عنوان ومفتاح مشروع Supabase الخاص بك في `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
*(ملاحظة: المنصة مهيأة أيضاً لتعمل بكامل وظائفها التفاعلية والتخزينية محلياً بشكل فوري حتى بدون إدخال المفاتيح لتسهيل الاختبار والتقييم)*.

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

## 🗄️ إعداد قاعدة بيانات Supabase / PostgreSQL

تم تضمين ملفات المخطط الكامل وسياسات الأمان في مجلد `supabase/`:
1. افتح مشروعك في [Supabase](https://supabase.com).
2. توجه إلى **SQL Editor**.
3. قم بتشغيل الكود الموجود داخل `supabase/schema.sql` لإنشاء الجداول وسياسات الأمان على مستوى الصفوف (Row Level Security - RLS) والفهارس.
4. قم بتشغيل الكود الموجود داخل `supabase/seed.sql` لملء المنصة بالبيانات الأولية للمسارات، الدورات، التحديات، والأوسمة.

## 🌐 النشر على Vercel وربط GitHub

1. قم برفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git add .
   git commit -m "feat: complete RAWAA Academy platform"
   git push origin main
   ```
2. ادخل إلى [Vercel Dashboard](https://vercel.com) واضغط **Add New Project**.
3. اختر مستودع المشروع من GitHub.
4. أضف متغيرات البيئة (`NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`) في قسم Environment Variables.
5. اضغط **Deploy**، وسيقوم Vercel ببناء ونشر المشروع تلقائياً مع دعم الـ Edge Network وضغط الصور.
